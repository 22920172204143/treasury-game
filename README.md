# 小房间探索游戏 🎮

一个使用 Three.js 开发的简单3D探索游戏，你可以控制角色在小房间里自由行走！

## 功能特性 ✨

- 🎯 **3D视角**：第三人称视角跟随角色
- 🚶 **角色控制**：使用WASD键控制角色移动
- 🦘 **跳跃功能**：按空格键跳跃
- 🎨 **精美场景**：包含小房间、桌子和箱子
- 💫 **光影效果**：实时阴影渲染
- 🛡️ **碰撞检测**：角色不会穿过墙壁和物体
- 🖱️ **视角控制**：可以用鼠标旋转和缩放视角

## 如何运行 🚀

### 方法一：直接打开（推荐）
1. 双击 `index.html` 文件
2. 游戏会在浏览器中自动打开

### 方法二：使用本地服务器
如果直接打开遇到跨域问题，可以使用本地服务器：

```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Python 2
python -m SimpleHTTPServer 8000

# 或使用 Node.js
npx http-server
```

然后在浏览器中访问：`http://localhost:8000`

## 操作说明 🎮

| 按键 | 功能 |
|------|------|
| W | 向前移动 |
| A | 向左移动 |
| S | 向后移动 |
| D | 向右移动 |
| 空格 | 跳跃 |
| 鼠标拖拽 | 旋转视角 |
| 鼠标滚轮 | 缩放视角 |

## 特色内容 🌟

### 房间设计
- 大小：20x20 单位
- 地板：灰色，带反射效果
- 墙壁：彩色墙面，前墙半透明便于观察

### 物品
- **桌子**：棕色木质桌子，包含桌面和四条桌腿
- **箱子**：红色箱子，带黄色条纹装饰

### 角色
- 蓝色胶囊形状
- 支持移动、跳跃
- 有碰撞体积，不会穿过物体
